# プライバシーポリシー (Privacy Policy)

## 日本語

### 1. 個人情報の収集
本拡張機能「やさしい文章」は、ユーザーの個人情報を一切収集しません。

### 2. データの外部送信
本拡張機能は、読み取ったウェブページの内容や、ユーザーが入力したライセンスコードを外部サーバーに送信することはありません。文章の変換、ふりがな付与、長文分割、読みやすさ計算はユーザーのデバイス上で処理されます。ユーザーが Premium へのアップグレードを選択した場合のみ、Stripe がホストする決済ページを新しいタブで開き、購入照合のためのランダムなインストール識別子を `client_reference_id` として付与します。

### 3. ストレージの利用
設定、体験期間、Premium 状態、ライセンスコード、ランダムなインストール識別子の保存のために `chrome.storage.local` を使用します。これらはユーザーのローカル環境に保存されます。

### 4. お問い合わせ
プライバシーに関するお問い合わせは、GitHub リポジトリの Issue 等を通じてご連絡ください。

## English

### 1. Data Collection
The "Sentence Simplifier" extension does not collect any personal information.

### 2. Data Transmission
This extension does not transmit any content from the web pages you visit or license codes you enter to external servers. Text simplification, furigana annotation, long-sentence splitting, and readability scoring are processed on your device. Only when you choose to upgrade to Premium, the extension opens a Stripe-hosted checkout page in a new tab and appends a random installation identifier as `client_reference_id` for purchase reconciliation.

### 3. Use of Storage
We use `chrome.storage.local` to save settings, trial state, Premium status, license codes, and a random installation identifier. This data is stored on your local device.

### 4. Contact
For privacy-related inquiries, please contact us via the GitHub repository issues.
