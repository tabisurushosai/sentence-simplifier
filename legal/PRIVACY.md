# プライバシーポリシー (Privacy Policy)

## 日本語

### 1. 個人情報の収集
本拡張機能「やさしい文章」は、ユーザーの個人情報を一切収集しません。

### 2. データの外部送信
本拡張機能は、読み取ったウェブページの内容や、ユーザーが入力した情報を外部サーバーに送信することはありません。すべての処理はユーザーのデバイス上（オフライン）で完結します。

### 3. ストレージの利用
設定情報の保存のために `chrome.storage.local` を使用しますが、これらはユーザーのローカル環境にのみ保存され、開発者や第三者がアクセスすることはありません。

### 4. お問い合わせ
プライバシーに関するお問い合わせは、GitHub リポジトリの Issue 等を通じてご連絡ください。

## English

### 1. Data Collection
The "Sentence Simplifier" extension does not collect any personal information.

### 2. Data Transmission
This extension does not transmit any content from the web pages you visit or any information you input to external servers. All processing is performed locally on your device.

### 3. Use of Storage
We use `chrome.storage.local` to save your settings. This data is stored only on your local device and is not accessible by the developer or any third parties.

### 4. Contact
For privacy-related inquiries, please contact us via the GitHub repository issues.
